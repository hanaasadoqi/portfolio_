## String

Sequence of characters; represents text.

- Allows for manipulation and processing of textual data in computer programs.
- Can be used to store and process large amounts of textual data
  - simple strings, complex sentences, paragraphs, books, etc.
- Implemented as an array of characters, with each character having a unique index position within the array

## Applications of String

### Plagiarism Checker

Strings can be used to find Plagiarism  in code and content

- Can be very performant using string matching algorithms
- Computers can indicate the percentage of code and text that match between two strings of text.

### Encoding/Decoding (Cipher Text Generation)

Can be used for encoding and decoding for the safe transfer of data from sender to receiver
  
- Ensure no one in the way of transmission can read data
  - Both active and passive attacks
- Text transferred as a message gets ciphered at the sender's end and decoded at the receiver's end

### Information Retrieval

Helps us to retrieve information from unknown data sources

- Large datasets may be used as inpuy
- String matching/retrieval modules helps us to retrieve important information

### Improved Filters for the Appropriate Suffix/Prefix Overlap Problem

Strings and its algorithms provide improved filters

- Problem is to find all pairs of strings from a given set
  - Prefix of one string is similar to a suffix of the other.

### Network Communication

Used to encode and decode sata sent over networks

- HTTP requests and responses

### File Handling

Used to manipulate file paths and names

- Can read and write files

### Data Analysis

Can be used to extract meaningful infghts from large amounys of text data

- Natural language processing
- Sentiment analysis

## Real-Time Applications

### Spam Detection

Strings can be used to serve as a spam detections system

- Concept of string matching algorithms are applied
- Spam filters use string matching to identify and discard the spam

### Bioinformatics

Strings can be used in Bioinformatics (DNA Sequencing)

- Can be used to solve issues or problems regarding genetic sequences
- Can help find patterns in DNA

### Intrusion Detection System

Strings can be used in intrusion detection systems.

- Packets with related keywords are found by applying string matching algorithms.

### Search Engine

Strings can be used in many search engine techniques

- Can be difficult to search for a specific content
  - Due to huge amount of uncategorized text data
- Engines organize the data and categorize the data string matching algorithms are used

### Inserting Character/String

**Input**:

- Character/string to be inserted
- Position/index

```javascript
function insert(str, char, idx) {
  return str.slice(0, idx) + char + str.slice(idx);
}
```

### Modifying Character

**Input**:

- Character to replace
- Position/index

```javascript
function modify(str, char, idx) {
  return str.substr(0, idx) + char + str.substr(idx + 1);
```

### Constructor

Called when an object is created either using the `new` keyword or not.

- When the constructor is used with `new`, it **creates and returns a new string object."
  - **Syntax**
    ```javascript
    const str = new String("Hello World")
    ```
- If not, `String()` **returns a primitive string value** rather than a string object.
  - converts values to its default primitive string value.
    - **used to convert data types** to strings.
  - **Empty string**
    ```javascript
    const str = String();
    // ""
    ```
  - **`undefined` or `null`**
    ```javascript
    const undefinedStr = String(undefined);
    // "undefined"
    const nullStr = String(null);
    // "null"
    ```
  - **Object literals**
    ```javascript
    const str = String({ key: 'value' })
    // "[object Object]
    ```
  - **Date Object**
    ```javascript
    const currentDate = new Date()
    const currentDateStr = String(currentDate)
    // Tue Oct 8 2024 08:14:32 GMT+0000 (Coordinated Universal Time)
    ```

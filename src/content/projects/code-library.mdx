## Project Scope

### Inclusions

- **User Authentication**: Secure login and registration system with password hashing.
- **Snippet Management**: Full CRUD (Create, Read, Update, Delete) operations for code snippets.
- **Tagging and Categorization**: Assign tags and categories to snippets for easier organization.
- **Search Functionality**: Advanced search using keywords, tags, and categories.
- **Code Editor Integration**: Rich text editor with syntax highlighting for multiple programming languages.
- **Sharing Capabilities**: Ability to set snippets as public or private and share them via unique URLs.
- **Responsive Design**: A mobile-first design approach to ensure optimal user experience across all devices.

### Exclusions

- **Real-time Collaboration**: No live multi-user editing or collaboration on snippets.
- **Version Control**: No built-in versioning for code snippets.
- **Third-Party Integrations**: Excludes integrations with external platforms such as GitHub or GitLab.

## Goals and Objectives

- **Improve Code Reusability**: Centralize code snippets to enable easy storage, retrieval, and reuse.
- **Enhance Organization**: Use tags and categories to keep code snippets organized.
- **Facilitate Sharing**: Provide options to share code snippets with specific individuals or the community.
- **User-Friendly Interface**: Ensure the platform is intuitive and responsive for an excellent user experience.
- **Scalability**: Architect the platform for future expansion to accommodate additional features and increased user load.

## Minimum Viable Product (MVP)

The MVP aims to deliver core functionalities that provide immediate value to users:

- **User Authentication**: Secure sign-up and login capabilities, including session management.
- **Snippet Management**: Users can create, edit, delete, and organize their code snippets.
- **Tagging and Categorization**: Tag snippets and organize them into predefined or custom categories.
- **Search Functionality**: Simple search that allows users to find snippets by title or content.
- **Code Editor**: Basic code editor supporting syntax highlighting for multiple programming languages.
- **Responsive Design**: Ensure a mobile-first approach for accessibility across devices.

### Features

#### Core Features

1. **User Authentication**
   - Email and password-based authentication with bcrypt password hashing.
   - User sessions and JWT-based authentication.
2. **Snippet Management**
   - Create, read, update, and delete snippets.
   - Syntax highlighting for over 20 programming languages using CodeMirror integration.
   - Rich text editor for editing code.
3. **Tagging and Categorization**
   - Assign multiple tags to each snippet for easy filtering.
   - Organize snippets into categories for better structure and retrieval.
4. **Search Functionality**
   - Keyword search with real-time results.
   - Advanced filtering based on tags and categories.
5. **Snippet Sharing and Permissions**
   - Ability to set snippets as public or private.
   - Shareable links for public snippets with view-only permissions.
6. **User Profiles (Post-MVP)**
   - Customizable user profiles including avatar, bio, and a list of public snippets.
7. **Import/Export of Snippets (Post-MVP)**
   - Ability to import/export snippets in various formats such as JSON, Markdown, or XML.
8. **Notifications (Post-MVP)**
   - Users receive email notifications when snippets are shared with them or updated.

## Architecture Overview

### Client-Server Architecture

The platform follows a client-server architecture where:

- **Client**: The frontend is a React-based Next.js application that handles user interactions and UI rendering.
- **Server**: Next.js API routes handle server-side logic, including database operations and authentication.

### Data Flow

1. **User Actions**: Triggered through the UI, such as creating a snippet.
2. **API Requests**: Client sends requests to Next.js API routes.
3. **Server Processing**: The server processes requests, interacts with MongoDB using Mongoose, and returns responses.
4. **UI Update**: The client updates based on the server's response.

### Component Hierarchy

- **Layout Components**: Header, Footer, Sidebar.
- **Pages**: Home, Dashboard, Snippet Detail, Add/Edit Snippet, Login, Signup.
- **Reusable Components**: Code Editor, SnippetCard, TagInput, SearchBar.

## Database Design

### Overview

The database is MongoDB, with two primary collections:

1. **Users**: Stores user profile information and authentication data.
2. **Snippets**: Stores code snippets, tags, and metadata.

### Schema Definitions

#### User Schema

- **username**: Unique string.
- **email**: Unique, validated email.
- **password**: Hashed password.
- **createdAt**: Date the user was created.

#### Snippet Schema

- **title**: Snippet title.
- **content**: Snippet content (code).
- **language**: Programming language.
- **tags**: Array of tags.
- **category**: Snippet category.
- **author**: References User.
- **isPublic**: Boolean flag for public/private visibility.
- **createdAt**: Timestamp for creation.
- **updatedAt**: Timestamp for the last update.

## Authentication Implementation

Authentication is managed by **NextAuth.js** with the following strategies:

### Password Authentication

- **Registration**: Passwords hashed with bcrypt before storage.
- **Login**: Credentials-based login with email and password.

### Social Authentication (Optional)

- **Google** and **GitHub** logins via OAuth.
  
### Security

- **JWT Tokens**: Session management via JWT.
- **Password Hashing**: Ensures no plain-text passwords.
- **HTTPS**: Mandatory in production for secure communication.

```bash
JWT_SECRET=your-jwt-secret
```
